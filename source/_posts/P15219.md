## Description

给你大小为 $N \times M (N,M\le 2000)$ 的白色网格，给定 $T \le 10^6$ 个矩形涂黑。有 $Q \le10^5$ 组询问，每次询问给定长和宽，问有多少个大小为给定长宽的纯白子矩形。

## Solution

首先，由于网格大小不大，因此对矩形涂黑是容易的，可以直接用二维差分解决。接下来问题就是如何统计白色子矩形，这似乎跟 [P1950 长方形 - 洛谷](https://www.luogu.com.cn/problem/P1950) 非常相似，我们试着能不能套用过来。

那么，设 $up_{i,j}$ 表示 $(i,j)$ 格子向上有多少个连续白格，$l_{i,j}$ 表示 $(i,j)$ 左边第一个 $up$ 值**小于** $up_{i,j}$ 的位置，$r_{i,j}$ 表示 $(i,j)$ 右边第一个 $up$ 值**小于等于** $up_{i,j}$ 的位置（这个等于很重要）。$l,r$ 数组可以直接用单调队列求出。对于一个 $(i,j)$，我们统计所有底部位于第 $i$ 行，高度小于等于 $up_{i,j}$，左端点位于区间 $(l_{i,j},j]$，右端点位于 $[j,r_{i,j})$ 的所有子矩形，这样就可以做到不重不漏。如下图，对于箭头所指的这一格能统计到的都已用不同颜色标出。

![](https://cdn.luogu.com.cn/upload/image_hosting/klzmdfpa.png)

> 为什么能不重不漏？考虑每个子矩形，设其底部在第 $i$ 行，它被计数当且仅当在 $up_{i,j}$ 取最小值时 $j$ 最小的 $(i,j)$ 位置。由于我们保证了一边是严格小于，一边是小于等于，这样当 $up$ 相等时会取最小的 $j$。

如何由此统计出答案呢？方便起见，不妨设 $L=j-l_{i,j}$（就是左边最多能扩展多少格），$R=r_{i,j}-j$，$H=up_{i,j}$。不难发现对于高度从 $1$ 到 $H$ 的所有矩形贡献都是一样的，因此只需要考虑横向的变化就可以了。

我们来把玩一组数据：$L=5,R=3$（长度为 $7$，中心在第 $5$ 格）。对于不同的宽度打表：
$$
width=1,2,3,4,5,6,7 \\
count=1,2,3,3,3,2,1
$$
规律其实非常明显，$[1,\min(L,R)]$ 是一个 $1$ 开头公差为 $1$ 的等差数列，$[\min(L, R),\max(L,R)]$ 是相同的值（都为 $\min(L,R)$，$[\max(L,R),L+R-1]$ 是一个公差为 $-1$ 的等差数列。那么，怎么统计答案的问题就迎刃而解了。不妨设 $ans_{w,h}$ 为宽度为 $w$，高度为 $h$ 时的答案，我们要支持两种操作：对一个矩形加上一个值，对一个矩形加上一个每一列（因为高度在列的位置）从上到下的等差数列。操作 1 是容易的，二维差分解决。对于操作 2，我们先来研究一列的情况。

对于 $a=\set{0,0,0,0,0,0,0,0}$，我们想要加上一个 $[2,5]$ 的公差为 $1$ 等差序列，也就是要变成 $\set{0,1,2,3,4,0,0,0}$。差分一下，得到 $d=\set{0,1,1,1,1,-4,0,0}$，这是不是好看多了？再差分一下：$t={0,1,0,0,0,-5,4,0}$，这下完美了，只需要修改 $3$ 个位置。也就是：$t_l \leftarrow t_l+1$，$t_{r+1} \leftarrow t_{r+1}-(r-l)$，$t_{r+2}\leftarrow t_{r+2}+(r-l+1)$。公差 $-1$ 同理。不过，你会发现对于首项不等于公差的序列是做不了的，但是其实只需要按照首项等于公差来做，最后整体加上一个偏移量，相当于区间修改，反正还得支持操作 1，顺便做了即可。

最后，由于是对一个矩形做修改，也就是在二阶差分下对一行某段修改，所以还得先二维差分（分清二阶和二维）上修改，还原，再二阶前缀和起来。

这样终于得到了 $ans_{h,w}$，每次询问 $\operatorname O(1)$ 回答，总复杂度 $\operatorname O(NM+T+Q)$，非常优秀。

注意，这个题的长宽方向有点诡异，而且给的涂黑矩形给的是点的位置而不是格子的位置，有点坑人。

附上 AC 代码（代码里 `ans` 数组复用了一下作为二维差分数组用于操作 1，`tmp` 用于维护等差序列）：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 2010;
int n, m, t, q, a[N][N], up[N][N], l[N][N], r[N][N], ans[N][N], tmp[N][N];
/*
up[i][j] 表示 (i, j) 往上第一个黑格子有多远
l[i][j] 表示左边第一个小于 up[i][j] 的位置
r[i][j] 表示右边第一个小于等于 up[i][j] 的位置 (防止算重)
*/
int que[N], tot; // 单调队列


void add(int x1, int x2, int y1, int y2, int v) {
    tmp[x1][y1] += v;
    tmp[x2 + 1][y1] -= v;
    tmp[x1][y2 + 1] -= v;
    tmp[x2 + 1][y2 + 1] += v;
}


signed main() {
    cin.tie(0)->sync_with_stdio(0);
    cin >> m >> n >> t >> q;
    while (t--) {
        int x1, y1, x2, y2;
        cin >> y1 >> y2 >> x1 >> x2;
        x1++;
        y1++;
        a[x1][y1]++;
        a[x2 + 1][y1]--;
        a[x1][y2 + 1]--;
        a[x2 + 1][y2 + 1]++;
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            a[i][j] = a[i][j] + a[i - 1][j] + a[i][j - 1] - a[i - 1][j - 1];
        }
    }

    for (int j = 1; j <= m; j++) {
        for (int i = 1; i <= n; i++) {
            if (a[i][j] > 0) up[i][j] = 0;
            else up[i][j] = up[i - 1][j] + 1;
        }
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            l[i][j] = 0;
            r[i][j] = m + 1;
        }

        // 两遍单调队列求出 l, r
        // 维护递增的单调队列
        tot = 0;
        for (int j = 1; j <= m; j++) {
            while (tot && up[i][que[tot]] >= up[i][j]) --tot;
            if (tot) l[i][j] = que[tot];
            que[++tot] = j;
        }
        tot = 0;
        for (int j = m; j; j--) {
            while (tot && up[i][que[tot]] > up[i][j]) --tot;
            if (tot) r[i][j] = que[tot];
            que[++tot] = j;
        }
    }

    // 统计答案
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int L = j - l[i][j], R = r[i][j] - j, H = up[i][j];
            // [1, min(L, R)] [1, H]
            add(1, 1, 1, H, 1);
            add(min(L, R) + 1, min(L, R) + 1, 1, H, -min(L, R)-1);
            add(min(L, R) + 2, min(L, R) + 2, 1, H, min(L, R));
            if (L == 1 && R == 1) continue;
            // [min(L, R) + 1, ] v = min(L, R)
            ans[min(L, R) + 1][1] += min(L, R);
            ans[L + R][1] -= min(L, R);
            ans[min(L, R) + 1][H + 1] -= min(L, R);
            ans[L + R][H + 1] += min(L, R);
            // [max(L, R) + 1, L + R - 1]
            add(max(L, R) + 1, max(L, R) + 1, 1, H, -1);
            add(L + R, L + R, 1, H, L + R - max(L, R));
            add(L + R + 1, L + R + 1, 1, H, -(L + R - max(L, R) - 1));
        }
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            tmp[i][j] += tmp[i - 1][j] + tmp[i][j - 1] - tmp[i - 1][j - 1];
            ans[i][j] += ans[i - 1][j] + ans[i][j - 1] - ans[i - 1][j - 1];
        }
    }
    for (int j = 1; j <= n; j++) {
        for (int i = 1; i <= m; i++) {
            tmp[i][j] += tmp[i - 1][j]; 
        }
        for (int i = 1; i <= m; i++) {
            tmp[i][j] += tmp[i - 1][j];
        }
    }
    
    while (q--) {
        int h, w;
        cin >> w >> h;
        cout << tmp[w][h] + ans[w][h] << '\n';
    }

    return 0;
}
```
