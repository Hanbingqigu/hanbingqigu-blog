## Description

给定平面上 $n \le 1000$ 个点，每个点有 $\frac 1 2$ 概率被选中，求选中的点集围成的凸包期望覆盖多少个点。

## Solution

首先期望转计数，考虑每个点被凸包覆盖的方案数。考察数据范围发现可以接受 $\operatorname O(n^2)$ 或者 $\operatorname O(n^2\log n)$ 的复杂度，因而可以对于每个点计算被凸包覆盖的方案数。

但这是不好解决的，考虑正难则反，对于每一个点计算没有被凸包覆盖的方案数。画图观察可以发现，如果一个点和一个凸包是相离的，那么一定可以找到一条线经过这个点和凸包相切（题目保证三点不共线，那么每条切线的切点是唯一的），如下图所示：

![](https://cdn.luogu.com.cn/upload/image_hosting/9asxbfvz.png)

套路地，我们可以用斜率最小的那条切线（也就是上图蓝色的那条）来计算贡献，这样就能做到不重不漏。这样做法就是显然的了，枚举每条直线，在这条直线下方和直线上的点都是确定选不选的，上方的点是随便选不选的，贡献就是 $2^\text{直线上方的点数}$。

实现细节上，设当前要计算贡献的点是 $P(x, y)$，以它建立坐标系后可以算出其他点与原点的夹角 $\alpha_i$，排序后双指针找到满足 $\alpha_r - \alpha_l \le \pi$ 的区间 $[l, r]$ 就是连接点 $l$ 这条直线上方的点。注意角度是循环的，因此需要加上 $2\pi$ 复制一遍。最后别忘了用总方案数减去不合法的。

> Tips: `atan2(y, x)` 是标准库的函数，接受一个坐标 $(x, y)$ 返回终边和原点到 $(x, y)$ 射线重合的弧度（注意参数顺序是颠倒的）。这个函数可以减少分象限讨论的过程。

总复杂度 $\operatorname O(n^2 \log n)$。

附上代码：

```cpp
#include <bits/stdc++.h>
#define PI 3.14159265358979323846
using namespace std;
const int N = 1e3 + 10, MOD = 1e9 + 7;
#define int long long
int n, x[N], y[N], ans, pw[N];


// 计算 idx 这个点的贡献
int solve(int idx) {
    int res = 1;
    vector<double> angles;
    angles.push_back(-0x3f3f3f3f);
    for (int i = 1; i <= n; i++) {
        if (idx == i) continue;
        int xx = x[i] - x[idx];
        int yy = y[i] - y[idx];
        angles.push_back(atan2(yy, xx));
    }
    // 复制一遍循环
    for (int i = 1; i <= n - 1; i++) {
        angles.push_back(angles[i] + 2 * PI);
    }
    sort(angles.begin(), angles.end());
    int r = 1;
    // 双指针找到 r
    for (int l = 1; l <= n - 1; l++) {
        while (r <= 2 * (n - 1) && angles[r] - angles[l] <= PI) {
            r++;
        }
        int len = r - l - 1;
        res = (res + pw[len]) % MOD;
    }
    return (pw[n] - res + MOD) % MOD;
}


signed main() {
    cin.tie(0)->sync_with_stdio(0);
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> x[i] >> y[i];
    }
    pw[0] = 1;
    for (int i = 1; i <= 1e3; i++) {
        pw[i] = pw[i - 1] * 2 % MOD;
    }

    for (int i = 1; i <= n; i++) {
        int t = solve(i);
        ans = (ans + t) % MOD;
    }
    cout << ans << '\n';
    return 0;
}

```
